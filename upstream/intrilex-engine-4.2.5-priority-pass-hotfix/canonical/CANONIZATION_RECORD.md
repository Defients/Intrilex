# Intrilex v4.1 Canonization Record

**Effective date:** July 26, 2026  
**Decision:** Intrilex v4.1 remains official canon; v4.0 remains immutable historical material.

The validated upstream SHA-256 set and authority order remain recorded in `INTRILEX_v4.1_CANON_LOCK.json`. Phase 5 changes implementation scope only; they do not alter canonical rules or upstream hashes.

## Change control

Rules reopen only for reproducible playtest or replay evidence containing an exact initial state, command sequence, expected outcome, actual outcome, and state/event hashes. A semantic change requires a new decision ID, synchronized artifacts, regression vectors, and a new rules version.

## Current implementation milestone

Roadmap Phases 2–5 are executable. The original Phase 2–4 aggregate remains unchanged, and the Phase 5 lifecycle gate is separately certified. Full ranks and later gameplay systems remain outside this release.
