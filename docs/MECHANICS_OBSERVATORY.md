# Mechanics Observatory

## Purpose

The Observatory answers what happened, through which mechanics, under what conditions, with what uncertainty, and which exact replays support or contradict the claim. It never changes legality or canonical state.

## Workspaces

- **Watch:** authorized board truth, semantic playback, Stack/trigger/private-choice evidence, score momentum, and checkpoint inspector.
- **Replays:** retained observed matches, governing corpus, verification, search, and matched comparison.
- **Mechanics:** 96 mechanic/card/timing records with opportunity-aware usage, impact, intervals, evidence grades, and replay links.
- **Synergies:** 221 stratified pair estimates, heatmap, directed graph, causal motifs, representatives, and counterexamples.
- **Compare:** policy fingerprints and ordered-matchup comparison within one compatible authority boundary.
- **Evidence:** capability truth, metric registry, anomalies, privacy boundary, canon ledger, and release identity.

## Drill-down contract

Every supported analytical object resolves toward retained evidence:

`cohort → metric → subgroup → match → replay → checkpoint → command/events/state diff`

When a match was not retained, the metric remains measured but the UI says that checkpoint evidence is unavailable rather than inventing a link.

## Semantic priority model

- Exhausted Pass: Mini-Turn Action, exact forced condition only.
- Response decline: policy decision only when responses exist.
- Automatic priority advance: engine orchestration, no policy input.
- Response-window closure: orchestration summary displayed in normal playback.

Raw priority commands are available only through the developer orchestration toggle.
