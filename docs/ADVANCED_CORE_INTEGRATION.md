# Advanced Core Integration

Simulation Lab v0.7.0 — Mechanics Observatory makes `core-advanced-authority` the default live simulation profile while preserving complete First Contact as a selectable supported profile.

## Engine boundary

Policies receive immutable semantic actions and an authorized state projection. The adapter keeps the raw command mapping in a private vault. A selected semantic action is resolved to exactly one engine command and submitted through `IntrilexEngine.execute`.

## Visual surfaces

The browser exposes command-checkpoint reconstruction for:

- PR and ER;
- authorized hands;
- mixed-visibility Swap Bar;
- GY and Exile;
- stack and priority;
- trigger queue;
- sealed private-choice state;
- Aegis, Board Lock, Exhausted, Voltage, limits, and printed skips;
- advanced declaration counts and retained-replay investigation.

Individual event records can be inspected, but canonical full-state snapshots exist at command checkpoints rather than after every emitted event.

## Batch proof

The shipped semantic catalog contains 100 global ordinals across all 25 ordered policy pairings. It was executed at two workers, four workers, and an independent clean four-worker rerun. All executions produced the same canonical result hash. A separate browser worker path executes bounded local campaigns.

## Fail-closed boundary

Complete Core is not claimed. Missing advanced continuations (hidden Super branches ⭐3/5/6/7), generated-effect authority, Sudden Death, modules, and multiplayer never silently fall back to simplified behavior. 10♦ Mimic, 10♣ Foundation, ⭐2 Hold, Voltage 3/4/5 Refine, and special scoring riders are now fully implemented.
