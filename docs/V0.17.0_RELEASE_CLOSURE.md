## New Modules

### Authority Layer (`play/authority/`)
- `legal-action-adapter.js` — Normalizes engine actions into player-facing contracts
- `priority-projection.js` — Derives priority context from engine state
- `visibility-projection.js` — Wraps privacy validation for UI-safe projections
- `reason-code-registry.js` — Structured reason codes for all rejection types

### Intelligence Layer (`play/intelligence/`)
- `action-explanation.js` — Three-layer explanation system (immediate, why, deeper)
- `decision-evidence.js` — Decision evidence with Rank Anatomy links

### Orchestration Layer (`play/orchestration/`)
- `declaration-flow.js` — UI state machine for action declaration and targeting
- `resolution-flow.js` — Structured event log and stack display

### State Layer (`play/state/`)
- `play-lifecycle.js` — UI lifecycle state machine (maps from engine SessionState)
- `session-lease.js` — Duplicate tab protection via BroadcastChannel

## Key Features

### Player-Facing
- **Priority banner**: Answers "Who may act? What window? What is waiting? What if pass?"
- **Action dock**: Actions grouped by timing class (Primary, Quick, Interrupt, Response, Score, Pass)
- **Target selection**: Explicit target selection UI for actions that require targets
- **Card inspector**: Right-click or Shift+click any card to see legal actions and details
- **Keyboard shortcuts**: P (pass), I (inspector), R (stack), ? (help), Esc (cancel)
- **Keyboard help overlay**: Press ? to see all shortcuts
- **Discard pile top card**: Shows the top card of the graveyard when legally public
- **Super and Spades badges**: Visual indicators for Super-eligible cards and Spades variants
- **Legal action indicators**: Hand cards show whether they have legal actions
- **Structured event log**: Human-readable event descriptions with indices
- **Priority timeline**: Collapsible timeline showing the priority sequence

### Tutorial
- **17 chapters** (up from 13): Added target selection, ordinary vs Spades, Super declaration, replay and evidence
- **Guidance modes**: OFF, ESSENTIAL, GUIDED, DETAILED — persisted per player
- **Concept dismissal**: Players can dismiss concepts they've already learned
- **Restart**: Players can restart the tutorial at any time

### Replay and Intelligence
- **Decision evidence**: Structured evidence for each decision point
- **Checkpoints**: Navigation checkpoints at each decision
- **Rank Anatomy links**: Each decision links to relevant Rank Anatomy concepts
- **History entries**: Public match summaries without private data
- **Trace entries**: Decision sequences without private data
- **Terminal screen links**: Direct links to Rank Anatomy and History from match end

### Save and Recovery
- **Duplicate tab protection**: Session lease via BroadcastChannel + localStorage
- **Explicit takeover**: Second tab must explicitly take control
- **Hash validation**: Save envelopes validated against content hash
- **Quarantine**: Corrupt saves moved to quarantine store
- **Version compatibility**: Engine and rules version checks on restore

### Accessibility
- **Keyboard navigation**: All actions accessible via keyboard
- **ARIA labels**: 60+ ARIA attributes on key elements
- **Reduced motion**: Respects `prefers-reduced-motion`
- **High contrast**: Respects `prefers-contrast: high`
- **Mobile responsive**: Inspector becomes bottom-sheet on mobile
- **Focus styles**: All interactive elements have visible focus indicators

## Conservation Principles

- **No invented causation**: Event log never claims "X caused Y"
- **No "best move" claims**: Tutorial and guidance never claim a move is objectively best
- **No engine mutation from UI**: Declaration flow is pure UI state
- **No Math.random in game logic**: All v0.17.0 modules are deterministic
- **No private data in history/traces**: Public summaries only
- **No engine imports in authority modules**: Modules work with snapshots, not engine
