# ADR-0001 — Engine Integration

## Decision

Retain the original v4.1.0 certified base for provenance and integrate the independently manifest-bound v4.2.5 Priority/Pass-corrected Advanced Core authority source through a single Lab adapter.

## Consequences

- The Lab never becomes a second rules engine.
- Complete First Contact remains available for regression and teaching.
- Advanced Core is the default live profile, but complete Core remains replay-only.
- Engine and Lab release archives remain separately identifiable and hashable.
- Governing v4.1.2 Interrupt timing is applied without generic skip penalties.
