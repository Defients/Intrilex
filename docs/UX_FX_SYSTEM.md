# UX and Semantic FX System

## Visual language

Graphite and blue-black structural surfaces are balanced with lighter analytical panels. Cyan represents neutral system information, magenta hostile pressure, amber uncertainty/warnings, green verified/supported state, and red errors. Color is always paired with text, iconography, shape, or position.

## Presets

- Observatory: balanced default.
- Theatre: compressed rail and expanded match board.
- Analyst: dense comparison and evidence surfaces.
- Compact: constrained viewport stack.

Presets affect layout only.

## FX authority

FX starts only after accepted semantic events. Rejections produce no success motion. Draw, score, counter, Ultra, fizzle, controller transfer, protection, and error treatments are CSS/SVG-driven. High speed coalesces cosmetic effects. Reduced motion, reduced sensory, and FX-off preserve the same labels and state changes.

## Playback

Normal timeline hides automatic priority commands and retains a closure summary. Controls separately step to the next policy decision, response decision, visible event, or engine command. State rewind is exact at command checkpoints; event rows do not invent intermediate states.
