# User Guide

1. Start with **Watch**. Choose Public, Player-authorized, or Omniscient view.
2. Use the semantic-step selector to move by policy decision, response decision, visible event, or raw command.
3. Keep `Show priority orchestration` off for normal watching; enable it only for engine debugging.
4. Open **Replays** to search retained matches or inspect the governing corpus.
5. In **Mechanics**, click a mechanic row to see the cohort, interval, formula, representatives, and limitations.
6. In **Synergies**, click a matrix cell, graph edge, or table pair to inspect stratified evidence and counterexamples.
7. In **Compare**, compare policy fingerprints and ordered matchups within the same version boundary.
8. Use **Evidence** for capabilities, metric formulas, anomalies, privacy, and integrity.
9. Press Ctrl/Cmd+K for the command palette.
10. Use reduced-motion, reduced-sensory, or FX-off when needed.

Public exports never contain private identities, raw RNG state, private choices, or command-vault payloads.
