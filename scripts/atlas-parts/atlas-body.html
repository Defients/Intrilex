INCOMING TRANSMISSION

MATT // INCOMING TRANSMISSION

MATT // INCOMING TRANSMISSION

Matt—

You actually played versions of this thing before there were formal names for half of what it was doing.

Back then, a lot of Intrilex strategy lived in instinct: hold this card, don't waste that one, wait because he might have the answer, score now because the window might disappear.

Years later, we finally tore the system apart mechanically.

And the strange part is that underneath all the accumulated bullshit—Supers, Ultras, Spades, Wilds, Anchors, Counters, Aegis, Guard, resets, steals, recursion and whatever else Deffy decided the game apparently needed—there is considerably more structure holding it together than either of us probably realized while actually playing it.

This isn't meant to tell you "the AI proved Intrilex is balanced."

It didn't.

It did something more interesting:

It mapped why certain ridiculous things aren't necessarily ridiculous once you account for what you sacrifice to use them—and exposed the places where that explanation stops being comfortable.

So this is the autopsy.

Not just what is strongest.

What is strongest when, why, for what price, and according to which definition of power.

You knew the creature before we had instruments to dissect it.

Now we do.

Welcome back.

— Vælix / Klÿz

06 // THE SPADES PROBLEM / SPADES PREMIUM

The Spades Premium

The top practical hierarchy is heavily dominated by exact Spade identities. This is not automatically imbalance — it is premium singleton tactical identity + scarcity + trackability.

Veteran Rule: Track the Spades.

Knowing which premium Spades have been spent changes the opponent's legal/safe decision tree. Once K♠ disappears, entire classes of plays become safer. Once 4♠ and 2♠ disappear, board commitment becomes dramatically safer. The state of the remaining Spade pool is effectively part of the game board even when those cards aren't OTT.

07 // THE 2♠ PROBLEM

The 2♠ Problem

Same primitive. Completely different economics. Copying an effect does not copy its cost.

Copying an effect does not copy its cost.

THE DISCOUNT APOCALYPSE

2♠ obtains a premium primitive at bargain-bin opportunity cost. K♠ obtains the same premium primitive by setting fire to the Swiss Army knife. Treat 2♠ not as a two-point card, but as a latent answer card whose cash value happens to be 2.

08 // K♠: THE OPTION-VALUE CARD

K♠: The Option-Value Card
