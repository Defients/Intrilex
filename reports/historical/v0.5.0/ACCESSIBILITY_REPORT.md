# Accessibility Report

- Status: **PASS for automated release scope**
- Language declaration, skip link, main landmark, labeled controls, visible focus, status text, and reduced-motion support are tested.
- Real Chromium UI smoke found no unnamed interactive controls in the exercised routes.
- Replay visibility modes are labeled as Public, Player, and Judge rather than encoded by color alone.
- Dynamic campaign and replay results use live regions.

This is not a complete manual WCAG audit. Screen-reader workflow review, zoom/reflow review, and broader contrast sampling remain recommended.
