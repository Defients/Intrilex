## 7. Existing Rank Intelligence Architecture

### What Exists (FACT)
- **Rank Power Module** (`packages/simulation-runtime/src/rank-power.mjs`, 414 lines): 6-axis RPI (selection, victory, score, board, response, ORV), cohort-relative normalization, confidence thresholds, balance watchlist
- **Rank Attribution** (`packages/simulation-runtime/src/rank-attribution.mjs`, 446 lines): Play form classification (base/suit/super/ultra/rank10/royal-marriage/generated/score/swap/solo-wild-copy), attribution status (exact/fractional/generated-origin/not-observable), variant entity classification
- **Rank Counterfactual** (`packages/simulation-runtime/src/rank-counterfactual.mjs`, 225 lines): Rank-level CDV, swap matrix, anchor selection
- **Rank Integration** (`packages/analytics/src/rank-integration.mjs`, 763 lines): ORV computation, `buildRankAnalytics()`, `buildVariantAnalytics()` (exists but NOT wired into build)
- **Rank Telemetry** (`packages/telemetry/src/rank-telemetry.mjs`, 639 lines): 16 rank metrics, 25 variant metrics (schema 5.1.0)
- **Variant Registry** (`packages/simulation-runtime/src/variant-registry.mjs`, 283 lines): All 13 Spades variants, 9 Super effects, entity tiers, profile filtering, `resolveSuperEffect()`
- **Card Face Data** (`apps/lab-web/src/card-face-data.js`): All 56 cards with canonical abilities, Spades distinctions, Super definitions
- **UI Skeleton**: `state.variantAnalytics` computed at browser-runtime, variant comparison section in `renderRanks`

### What's Missing (FACT)
1. **Variant analytics NOT in deterministic build** — `buildObservatoryAnalytics()` calls `buildRankAnalytics()` but NOT `buildVariantAnalytics()`. Variant analytics is computed at browser-runtime from summaries with no hash identity.
2. **No canonical Rank Anatomy registry artifact** — the variant registry exists in code but is not serialized as a generated artifact with authority hashes.
3. **No Rank 2 eligibility record** — the variant registry declares 2♠ eligible (solo-wild-copy distinction) but there's no formal eligibility record with authority refs.
4. **Duplicate `buildVariantAnalytics` implementations** — exists in both `browser-analytics.js` and `browser-rank-analytics.js` (DRY violation).
5. **No Super declaration funnel** — declaration-level vs effect-level statistics not separated in UI.
6. **No individual Super effect dossiers** — effect-level cards not rendered.
7. **No frequency-potency quadrant** — no visualization separating frequency from potency.
8. **No origin filter** — no UI for natural/generated/copied/mimicked/replayed filtering.
9. **No contribution decomposition** — no UI showing ordinary/Spades/Super contribution shares.
10. **No evidence drawer** — no drill-down from metric to replay checkpoint.
