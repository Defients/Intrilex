## Falsification Mandate

Per the release protocol, this report documents the active attempts to falsify the v0.16.0 release. Each test below was designed to FAIL if a specific claim is false. All tests pass, meaning the claims survived falsification.

## Falsification Tests

### F1: A Spades card inside a Super must not inflate ordinary Spades use

**Claim:** The registry separates Spades variant from Super declarations. Spades variant effect IDs must not overlap with Super effect IDs.

**Test:** `test/rank-anatomy.test.mjs` — "FALSIFICATION: A Spades card inside a Super must not inflate ordinary Spades use"

**Result:** PASS — For every rank with both a Spades variant and Super effects, the Spades variant effect IDs do not overlap with Super effect IDs. The separation is enforced at the registry level.

### F2: Rank 2 must not be incorrectly omitted

**Claim:** Rank 2 is eligible for Spades variant analysis per canonical authority.

**Test:** `test/rank-anatomy.test.mjs` — "FALSIFICATION: Rank 2 must not be incorrectly omitted"

**Result:** PASS — Rank 2 is present in the registry with `spadesEligible: true` and `reasonCode: DISTINCT_SPADES_EFFECT`. The eligibility is backed by the variant registry and card-face-data authority.

### F3: Low-sample variants must not dominate rankings

**Claim:** The registry defines evidence grades that prevent low-sample dominance.

**Test:** `test/rank-anatomy.test.mjs` — "FALSIFICATION: Low-sample variants must not dominate rankings"

**Result:** PASS — Evidence grades include "insufficient", "provisional", and "weak". The confidence classification system (HIGH/MEDIUM/LOW/INSUFFICIENT) is applied per-variant based on opportunity count thresholds (100/30/8).

### F4: Missing effects must not become zero-valued effects

**Claim:** Ranks without Supers have empty supers arrays, not zero-valued entries.

**Test:** `test/rank-anatomy.test.mjs` — "FALSIFICATION: Missing effects must not become zero-valued effects"

**Result:** PASS — Ranks 9, 10, Q, K, RJ, BJ all have `supers.length === 0` and `superEffectCount === 0`. No zero-valued Super entries exist.

### F5: No display label is used as primary identity

**Claim:** Effect IDs and rank IDs are stable identifiers, not display labels.

**Test:** `test/rank-anatomy.test.mjs` — "No display label is used as primary identity"

**Result:** PASS — Every Super has both an `effectId` (stable) and a `displayName` (human-readable). The `effectId` is never equal to the `displayName`.

### F6: Descriptive classifications do not include balance verdicts

**Claim:** The registry's descriptive classifications never include balance verdicts.

**Test:** `test/rank-anatomy.test.mjs` — "Descriptive classifications do not include balance verdicts"

**Result:** PASS — No classification includes forbidden balance verdicts ("overpowered", "underpowered", "broken", "balanced", "useless", "mandatory").

### F7: Registry hash is deterministic

**Claim:** The canonical Rank Anatomy registry hash is deterministic across invocations.

**Test:** `test/rank-anatomy.test.mjs` — "Registry hash is deterministic"

**Result:** PASS — Two invocations of `canonicalRankAnatomyRegistry(hashCanonical)` produce identical 64-character hex hashes.

### F8: Variant analytics is in the build artifact

**Claim:** The observatory analytics.json contains variantAnalytics with hash identity.

**Test:** `test/rank-anatomy.test.mjs` — "Observatory analytics.json contains variantAnalytics"

**Result:** PASS — The artifact contains `variantAnalytics` with `variantMetrics`, `rankComparisons`, and `metricRegistryHash`.

### F9: Analytics schema version is 4.2.0

**Claim:** The analytics schema version was incremented to reflect the addition of variant analytics.

**Test:** `test/rank-anatomy.test.mjs` — "Observatory analytics schema version is 4.2.0"

**Result:** PASS — `schemaVersion: "4.2.0"` in the generated artifact.

### F10: All 9 Super effects have stable IDs

**Claim:** The 9 Super effects have stable, canonical effect IDs.

**Test:** `test/rank-anatomy.test.mjs` — "All 9 Super effects have stable IDs"

**Result:** PASS — All 9 effect IDs match the expected set: super-ace, super-two, super-three-raid, super-four-exchange, super-five-recycle, super-six-dig, super-seven-topdeck, super-eight-scuttle, super-jack-tempo.
