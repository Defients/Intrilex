## Repair Log

### 2025 — Section 3.3 Anchor Inversion Repair (commit 8f239ee)

**Root cause:** The `verifyAnchorBinding` function in `simulation-runtime/src/counterfactual.mjs`
inverted the authority closure in two ways:

1. **decisionId re-derivation:** It derived `decisionId` from
   `{matchId, decisionIndex, checkpointHash}` using a self-invented formula (full hash,
   truncated to 16 chars). This **rejected** authentic decisionIds (e.g.
   `DT-05f2e10a588e1be6`) that were originally derived from a 16-character truncated
   checkpoint hash, while **accepting** synthetic ids that matched the formula.
2. **actor/seat presence-only check:** It checked for the *presence* of `actorId` and
   `seat` but never validated their values against the restored engine decision frame,
   allowing incorrect values to pass.

**Fix:** Created one authoritative anchor resolver
(`packages/decision-intelligence/src/anchor.mjs`) — pure, zero-dependency, shared
verbatim by Node and (pending) browser. The resolver:
- **RESOLVES** `decisionId` from a real retained Decision Evidence record
  (`config.retainedDecisionEvidence`), never re-derives it. Synthetic ids fail.
- **VALUE-MATCHES** `actorId` and `seat` against the restored engine decision frame.
- **REQUIRES** all state/command/replay hashes to be complete 64-hex canonical form;
  truncated hashes fail. Replay content hash cannot substitute for before-state authority.
- **IDENTIFIES** the historical (replay-selected) action from retained evidence and
  requires it to reproduce the recorded post-action state.
- **DERIVES** the decision-to-command mapping from full command hashes and replay
  execution; ambiguity is rejected.

**Verification:**
- 39 new anchor authority tests (`test/v0.10.0-anchor-authority.test.mjs`): all pass.
  33 pure resolver tests + 6 wired `runPairedCounterfactual` tests.
- Contract tests: 32/32 pass (updated to use real retained authority).
- Behavioral tests: 106/117 pass (11 pre-existing failures in Campaign/Browser/HYBRIX/
  Benchmark/CI — unchanged from baseline, no regressions).
- Probe (`scripts/probe-anchor-inversion.mjs`): authentic=COMPLETED, synthetic=
  DECISION_ID_MISMATCH, wrong actor=ACTOR_ID_MISMATCH, wrong seat=SEAT_MISMATCH,
  truncated=TRUNCATED_BEFORESTATEHASH, replay-content-hash-as-checkpoint=
  BEFORE_STATE_HASH_MISMATCH, no-retained-evidence=MISSING_RETAINED_DECISION_EVIDENCE.

**Authentic evidence used:** Match `M-161726cc9a3a57e46f9c`, decision
`DT-05f2e10a588e1be6`, 16-char checkpoint hash `72983c63414fa6cd` (prefix of the full
before-state hash `72983c63414fa6cd999a8a021f707b6ad5c25c071a82d5d3de10f560d79ebc97`).
