## 6. Inverted anchor validator — decisive probe (Section 3.3)

The prompt's prior post-Cascade probe reported:

| Probe | Prior observed result |
|---|---|
| Authentic trace id `DT-05f2e10a588e1be6` | `NOT_SUPPORTED — DECISION_ID_MISMATCH` |
| Synthetic id `DT-c61316c71866ace7` | `COMPLETED` |
| Same synthetic id, actor `WRONG`, seat `99` | Still `COMPLETED` |

Both exact ids exist in the selected baseline
(`sample-data/autonomy/decision-traces/M-161726cc9a3a57e46f9c.json` contains
`DT-05f2e10a588e1be6`; the synthetic id is reproducible from the validator formula).
The probe was reproduced **unchanged** against the live baseline
(`scripts/probe-anchor-inversion.mjs`, evidence in
`reports/_probe-anchor-inversion-output.txt`):

```
matchId=M-161726cc9a3a57e46f9c
authentic decisionId (retained trace)=DT-05f2e10a588e1be6
authentic trace checkpointHash (16-char)=72983c63414fa6cd
restored full beforeStateHash=72983c63414fa6cd999a8a021f707b6ad5c25c071a82d5d3de10f560d79ebc97
beforeStateHash starts with trace checkpointHash? true
synthetic decisionId (validator formula)=DT-c61316c71866ace7
authentic == synthetic? false

1. AUTHENTIC retained decisionId: selected.status=NOT_SUPPORTED reason=DECISION_ID_MISMATCH
2. SYNTHETIC decisionId (validator formula): selected.status=COMPLETED
3. SYNTHETIC + wrong actor: selected.status=COMPLETED
4. SYNTHETIC + wrong seat: selected.status=COMPLETED
5. SYNTHETIC + wrong actor AND wrong seat: selected.status=COMPLETED
```

**Root cause:** the authentic retained Decision Evidence `checkpointHash` is the 16-char
truncation of the full before-state hash. The authentic `decisionId` was derived from that
16-char form. The Cascade validator derives the expected `decisionId` from the **full**
hash, so it (a) rejects the authentic id and (b) accepts any id synthesized from its own
formula — including `DT-c61316c71866ace7`, byte-identical to the prompt's synthetic id.
`actorId` and `seat` are checked for presence only and are never matched against the
restored decision frame, so wrong actor/seat pass.

This inversion is represented by red behavioral tests before any repair (Phase 1).
