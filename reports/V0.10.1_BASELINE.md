## Confirmed defects (release blockers)

### A. Hidden-information projection and export leak

**Status:** CONFIRMED — release blocker

Root cause in `runtime/autonomy-engine-dist/src/views.js`:
- `publicStateView()` hides card identities for `_HAND`, `faceDownTrap`, `swapBarFaceDown`, `STAGING/draftFaceUp=false`, and `privateChoiceHeldBy` cards.
- **Does NOT hide draw-pile (zone `DP`/`dp`) card identities.** Draw-pile cards retain real identities in both public and player views.
- `privateStateView()` has the same gap and additionally does **not** strip the `rng` field from the player view state.

Evidence:
- `sample-data/autonomy/lab-replays/public/M-09782322...json`: public frame `state.cards` has `PUB-` handles but `identity` field shows real values (Q, Q, 6, 4, 5) for DP-zone cards.
- `sample-data/autonomy/lab-replays/authorized/M-09782322...json`: `playerViews.P1.cards` shows real identities (CORE-015=Q, CORE-016=Q, ...) for DP-zone cards. `playerViews.P1.rng` contains `{seed: 784256783, cursor: 53}`.
- Browser `apps/lab-web/src/app.js` `cardToken()` renders whatever `card.identity` is present; no viewer-role filtering at render time.
- Browser loads the entire authorized artifact (including `omniscientState`) even in player mode — omniscient state is in JS heap.

Existing privacy tests are vacuous: `test/privacy.test.mjs` checks for `"C-\d{3}"` pattern but card identities are single-letter (Q, 6, 4, 5, A, K). `test/hidden-info.test.mjs` only checks CT-120 (which has an empty draw pile).

### B. HYBRIX cross-run mutable-state leakage

### D. Campaign status and accounting truth

**Status:** CONFIRMED — `packages/simulation-runtime/src/campaign.mjs:83-87`:

- `campaignStatus: failures.length === 0 ? 'PASS' : 'FAIL'` — PASS when no errors, even if every match was aborted/DECISION_LIMIT.
- No mutually exclusive terminal categories. No invariant check.

HYBRIX benchmark: `reports/hybrix-benchmark.json` has `accountingInvariant: false` (1305+1267+231+0+6=2809 ≠ 3600 total). Script `scripts/benchmark-hybrix.mjs` computes the invariant but never checks it or exits nonzero.

## Authority map

### Data flow

```
Engine (runtime/autonomy-engine-dist/src/engine.js)
  ↓ execute(state, command) → { state, accepted, events, error }
Simulation runtime (packages/simulation-runtime/src/runtime.mjs)
  ↓ runMatch() → semantic records, traces, decisions
  ↓ projectFrame() via views.js → publicStateView / privateStateView / omniscient
Engine adapter (packages/engine-adapter/src/adapter.mjs)
  ↓ public-projection.mjs → createReplayScopedPublicProjector (PUB- handles, strip rng/seed)
Replay artifacts (sample-data/replays/{public,authorized}/)
  ↓ browser fetch
Browser (apps/lab-web/src/app.js)
  ↓ state.visibility = 'public' | 'player' | 'judge'
  ↓ currentState() selects frame.state | playerViews[viewer] | omniscientState
```
