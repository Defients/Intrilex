## 3. Behavioral & Logic Diagnostics (Reality vs Intent)

### 3.1 CRITICAL: Test suite was failing (7 failures) — FIXED during audit

**Observed (before fix):** `pnpm test` → 523 tests, 516 pass, **7 fail**.
**Truth claim:** README says "437 tests across 32 test files"; ledger says "532 tests, 532 pass"; self-audit.json says "532 tests, 532 pass, 0 fail".
**Root cause:** `sample-data/autonomy/decision-trace-index.json` was **missing**. The 29 trace shard files existed in `decision-traces/`, but the index file that lists them had never been generated (or was deleted). `scripts/generate-decision-traces.mjs` writes this index (line 60), but `campaign:traces` had not been run to completion. `scripts/build.mjs` does NOT generate traces — it only copies `sample-data/` to `dist/`, so the missing file propagated to dist.
**Affected tests:** `browser-workspace-liveness.test.mjs` (BL-07), `v0.10.0-behavioral.test.mjs` (Decision Evidence Reconciliation, Rule Audits, Adversarial: Traces Loading — 4 subtests).
**Fix applied:** Ran `node scripts/generate-decision-traces.mjs --resume` (rebuilt index from existing shards: 29 matches, 2248 traces), copied index to `apps/lab-web/dist/data/autonomy/`.
**After fix:** `pnpm test` → **533 tests, 533 pass, 0 fail**.

**Gap:** The build pipeline has a **missing dependency**: `build.mjs` should either (a) run `generate-decision-traces.mjs --resume` before copying sample-data, or (b) fail loudly if `decision-trace-index.json` is missing. Currently it silently ships a broken dist.

### 3.2 Truth Drift in counts

**Observed:**
- README claims "437 tests across 32 test files" — **stale** (actual: 533 tests, 37 files).
- self-audit.json claims "532 tests, 532 pass" — **stale** (actual: 533).
- Implementation ledger claims "532 tests" at Phase 14 — **stale** (a test was added without re-counting).
- `scripts/ci.sh` comment/doc claims "51 stages" — **stale** (actual: 56 stages).
- `docs/ARCHITECTURE.md` says "seven-workspace browser Observatory" — **stale** (actual: 12 workspaces).

**Intent:** The codebase has a "truth restoration" philosophy (see `V0.11.0_TRUTH_DRIFT.md`) with a stated precedence: executable behavior > engine source > certified replays > contracts > analytics > docs > historical > comments. The counts drifted again after the last truth-restoration pass.

### 3.3 Rank Power Observatory — data IS present (audit inference corrected)

**Initial inference:** `/ranks` workspace may render empty (rank power data pipeline not wired).
**Verification (FACT):** `apps/lab-web/dist/data/observatory/analytics.json` **does** contain a fully-populated `rankPower` object with all 15 canonical ranks, each having: RPI, decisionPower, confidence (all HIGH), six-axis power profile (selection/victory/score/board/response/decisionValue), raw metrics, and CDV. The balance watchlist flags Rank 7 (RPI 0.184) and BJ (RPI 0.147) as underpowered. The `/ranks` workspace (`renderRanks()` at app.js:298) loads this via `state.observatory.rankPower` (set at app.js:84) and renders it correctly.
**Remaining risk:** The generation path (observatory analytics → `rankPower` embedded in analytics.json) is not documented as an explicit build dependency. `scripts/build.mjs` copies pre-generated `sample-data/observatory/analytics.json` to dist; it does not regenerate it. If the source analytics.json is lost, a clean rebuild would produce an empty `/ranks`.

### 3.4 Card Face Registry — fail-visible scaffold by design

**Observed:** `card-face-data.js` has 8 authoritative cards (4 Kings + 4 Tens). The other 46 exact identities fall through to `genericCardDefinition()` which renders a scaffold with note "Its full suit-specific rules have not yet been entered into Card Face Registry v1." This is **intentional fail-visible** behavior (documented in `docs/CARD_FACE_RENDERER.md`), not a bug.

### 3.5 HYBIX AI — heuristic, not learned

**Observed:** HYBIX has 8 layers (perception, cognition, personality, memory, coordination, difficulty, failsafe, debug) with 15 policy variants. Cognition uses "Hybrid BT spine + utility scoring + bounded GOAP" (`cognition.mjs`). 
**INFERENCE:** This is a sophisticated heuristic AI, not a learned model. The `KNOWN_LIMITATIONS.md` item 10 confirms: "The shipped policies are deterministic behavioral baselines, not optimal agents." This is correctly scoped.

### 3.6 Schema validation absent

**Observed:** 5 JSON schemas exist in `schemas/` but are **never validated at runtime** — no AJV, jsonschema, or validateSchema imports anywhere. Schemas are referenced only in release manifests.
**Intent (inferred):** Schemas are contract specifications for external consumers and release documentation, not runtime guards. This is a gap if any producer drifts from the schema.

### 3.7 WSL browser steps silently skip

**Observed:** `browser-parity.mjs`, `browser-ui-smoke.mjs`, `verify-extracted.mjs` detect WSL and `return 0` (skip) instead of failing. CI counts these as SKIP (fixed in Phase 7), but the skip means browser parity is **not proven on WSL**.
**Intent:** Intentional — Chromium CDP isn't available in WSL. Documented limitation.
