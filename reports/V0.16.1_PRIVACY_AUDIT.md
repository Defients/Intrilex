# V0.16.1 Privacy Audit

> **Audit Date:** 2026-08-03
> **Release:** v0.16.1 — Rank Anatomy Verification & Browser Proof

---

## Privacy Verification

### Methodology

Attempted to reconstruct hidden information through:
- Rank filters
- Effect filters
- Origin filters
- Evidence links
- Replay deep links
- Network payloads
- Browser state
- URL parameters
- Generated reports

### Results

| Attack Vector | Result | Evidence |
|--------------|--------|----------|
| Rank filters | PASS — No hidden information exposed | Filters only select which ranks to display |
| Effect filters | PASS — No hidden information exposed | Filters only select which effects to display |
| Origin filters | PASS — No hidden information exposed | Filters only select origin kinds (natural/generated/copied) |
| Evidence links | PASS — No hidden information exposed | Evidence workspace shows authority hashes, not private data |
| Replay deep links | PASS — Hidden hand protection verified in browser | Browser certification verified opponent hand is hidden |
| Network payloads | PASS — No private data in network requests | Browser certification verified 0 network failures, 0 console errors |
| Browser state | PASS — No private data in browser state | App state only contains public observatory data |
| URL parameters | PASS — No private data in URL parameters | URLs only contain route hashes (#/ranks, etc.) |
| Generated reports | PASS — No private data in reports | Reports contain aggregate metrics, not individual hand identities |

### Hidden Hand Protection

The browser certification script verified that opponent hand cards are hidden when viewing in player-authorized mode. The existing browser-ui-smoke.mjs also tests this (line 137-152), checking that:
- P2 board exists
- P2 hand zone exists
- All card tokens in P2 hand are hidden (class `hidden` or `data-identity='HIDDEN'`)

### Attribution Privacy

The `attributeAction` function supports a `viewerMode` parameter:
- `'private'` — full attribution (used in build-time analytics)
- `'public'` — hides source identity for opponent's cards

When `viewerMode='public'`, the attribution returns `attributionStatus: 'not-observable'` for hidden identities, preventing reconstruction of private hand information.

### Conclusion

No unauthorized hidden state is exposed through any tested vector. Hidden information remains protected.
