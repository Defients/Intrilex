# V0.16.1 Falsification Campaign

> **Audit Date:** 2026-08-03
> **Release:** v0.16.1 — Rank Anatomy Verification & Browser Proof

---

## Falsification Methodology

Each attack attempts to break a specific claim of the release. An attack succeeds (falsifies the claim) if it produces a counterexample. An attack fails (confirms the claim) if no counterexample is found.

## 20 Mandatory Attacks

### Attack 1: SCHEMA_VERSION consistency
**Claim:** All schema version references are consistent at 4.1.0.
**Attack:** Search all source files for SCHEMA_VERSION references and verify they all say 4.1.0.
**Result:** PASS — All references to SCHEMA_VERSION in analytics.mjs, analytics.schema.json, browser-analytics.js, and version.js are 4.1.0.

### Attack 2: Rank 2 eligibility semantics
**Claim:** Rank 2 has DISTINCT_SPADES_PLAY_FORM but no DISTINCT_PRINTED_SPADES_EFFECT.
**Attack:** Verify the spadesEligibilityRecord function returns the correct reason code for Rank 2.
**Result:** PASS — Rank 2 eligibility record has DISTINCT_SPADES_PLAY_FORM, not DISTINCT_PRINTED_SPADES_EFFECT.

### Attack 3: No duplicate buildVariantAnalytics
**Claim:** browser-rank-analytics.js has been eliminated.
**Attack:** Search for browser-rank-analytics.js in the source tree and dist.
**Result:** PASS — browser-rank-analytics.js no longer exists in src or dist. All imports redirected to browser-analytics.js.

### Attack 4: CI stage parity
**Claim:** ci.mjs and ci.sh have the same number of stages.
**Attack:** Count stages in both files and compare.
**Result:** PASS — Both ci.mjs and ci.sh have 69 stages.

### Attack 5: Attribution fixture coverage
**Claim:** 22 attribution fixtures pass with exact expected counts.
**Attack:** Run the attribution fixture test file and verify all 29 tests pass (22 fixtures + 7 conservation/invariant tests).
**Result:** PASS — 29/29 tests pass.

### Attack 6: Browser certification with real Chrome
**Claim:** The production build works in a real Chrome browser.
**Attack:** Run browser-certification-v0161.mjs with real Chrome via CDP.
**Result:** PASS — 27/27 browser certification tests pass with 0 console errors, 0 network failures, 0 exceptions.

### Attack 7: All 16 routes render
**Claim:** All 16 routes (landing, play, rules, sim, watch, replays, history, mechanics, cards, synergies, ranks, compare, traces, branches, diagnostics, evidence) render correctly.
**Attack:** Navigate to each route in Chrome and verify page title and content.
**Result:** PASS — All 16 routes render with correct page titles and expected content.

### Attack 8: No horizontal overflow at any viewport

**Attack:** Set each viewport via CDP Emulation.setDeviceMetricsOverride and check scrollWidth vs clientWidth.
**Result:** PASS — No horizontal overflow at any viewport on the Ranks page.

### Attack 9: Reduced motion emulation

**Result:** PASS — matchMedia('(prefers-reduced-motion: reduce)').matches returns true.

### Attack 10: Keyboard accessibility
