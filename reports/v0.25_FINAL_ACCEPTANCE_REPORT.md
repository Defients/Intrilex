## Intentional Non-Closures (Documented)

1. **Tutorial for network matches:** Tutorials are single-player learning experiences against AI. They are intentionally not initialized for network matches. This is by design, not a bug.

2. **Autosave for network matches:** Network matches use server-side durable persistence (SqliteMatchStore) instead of client-side IndexedDB autosave. This is intentional — the server is the authority.

3. **Spectator chat:** Spectators do not receive chat messages. This is out of scope for v0.25 (spectators are read-only observers).

4. **Real browser behavioral certification:** The browser preview is available at http://127.0.0.1:4173 for manual inspection. Automated CDP-based certification requires Chrome/Chromium and is environment-dependent.
