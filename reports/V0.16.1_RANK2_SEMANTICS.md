## The Contradiction

The v0.16.0 predecessor contained an apparent contradiction:

1. Rank 2's printed ability (Solo Wild Copy) is **the same** for all four suits (2♣, 2♦, 2♥, 2♠).
2. Rank 2 was classified as Spades-analytics eligible with reason code `DISTINCT_SPADES_EFFECT`.

If the printed ability is the same across suits, how can there be a "distinct Spades effect"?

## Resolution

The contradiction arises from conflating three distinct concepts:

1. **Printed effect** — the card text describing what the card does
2. **Play form** — the set of legal declarations available when playing the card
3. **Resolution semantics** — how the declared action resolves in the engine

For Rank 2:
- **Printed effect:** Same for all suits. "A single 2 may be played alone as a wild copy of one same-suit rank 3–7 card's Base (🛠) effect."
- **Play form:** Different for 2♠. The printed text states: "Suit-specific enhanced Base modes (3♠, 4♠, 6♠, 7♠) require the 2 to be 2♠." This means 2♠ can target spade-enhanced Base modes that 2♣/2♦/2♥ cannot target.
- **Resolution semantics:** Different for 2♠. When 2♠ targets a spade-enhanced Base mode, the resolution follows the spade-enhanced resolution path, not the ordinary Base resolution path.

## UI Language

The UI must distinguish:
- **Printed Spades effect** — NOT applicable to Rank 2
- **Spades-specific play form** — YES, 2♠ has a distinct targeting scope
- **Spades-specific resolution** — YES, 2♠ resolves through spade-enhanced paths
- **Independent Spades analytics eligibility** — YES, independent Spades statistics answer a meaningful question

The UI must never show "Unique Spades Effect" for Rank 2. It should show "Distinct Spades Play Form" or equivalent precise language.

## Conclusion

Rank 2 is eligible for independent Spades variant analysis. The distinction is in the play form (targeting scope), not in a printed effect. The reason code `DISTINCT_SPADES_PLAY_FORM` is semantically precise and does not conflate printed effects with play forms.
