# runtime/vendor-dist/

## Origin

This directory contains a **pre-compiled engine distribution** (TypeScript → JavaScript)
that was placed manually as a vendor artifact. It is NOT generated by any build script
in this repository. The `scripts/build-engine-patch.mjs` script generates
`runtime/autonomy-engine-dist/` from `upstream/intrilex-engine-4.2.6-*/dist/`, but
`vendor-dist/` has no corresponding upstream source or build step.

## Relationship to autonomy-engine-dist

`vendor-dist/` is a **strict subset** of `autonomy-engine-dist/`. It contains the same
base engine modules (phases 8-20, ranks, replay, simulation, state, etc.) but EXCLUDES
the autonomy and core-authority modules:

- `autonomy.js` — NOT present
- `core-advanced.js` — NOT present
- `core-authority.js` — NOT present
- `core-autonomy.js` — NOT present
- `core-effects.js` — NOT present
- `core-private-choice.js` — NOT present
- `core-response.js` — NOT present

This makes `vendor-dist/` a public-safe distribution: it contains the engine modules
needed for certified replay parsing and verification, but not the AI/autonomy logic.

## Usage

The `@intrilex/engine-adapter` package imports ONLY `phase16.js` from this directory
(`packages/engine-adapter/src/adapter.mjs:11`):

```js
const vendorRuntime = path.join(root, 'runtime/vendor-dist/src');
const phase16 = await import(moduleUrl(vendorRuntime, 'phase16.js'));
```

`phase16.js` provides `parseCertifiedReplay`, `verifyCertifiedReplay`,
`publicCertifiedReplayView`, and `serializeCertifiedReplay` — the certified replay
format used for public match sharing.

All other engine modules are imported from `runtime/autonomy-engine-dist/`.

## Integrity

All files in this directory are tracked in `release/RELEASE_MANIFEST.json` with
SHA-256 hashes. The release verification process (`scripts/release-verify.mjs`)
checks these hashes against the manifest.
